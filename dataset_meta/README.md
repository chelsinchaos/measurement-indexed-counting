# Dataset for "Measurement-Indexed Counting"

Generated by `code/run_all.py` (verification run 1); every quantity except wall-clock time is deterministic
from the seeds recorded in each file. `MANIFEST.json` lists the SHA-256 of every file and the environment.

- `instances/*.cnf` — every formula used, in DIMACS; the first comment lines give the generator and seed.
  `toy_*`: random bounded-occurrence 3-CNFs (every variable in at most three clauses). `fibre_*`: formulas
  behind the fibre-loop groups. `grid_WxH`: independent sets of the grid graph (one binary clause per edge).
  `random3cnf_*`: uniform random 3-CNFs; literal weights in the comments when weighted.
- `designs/*.json` — every measurement design of the toy: per point `t`, the groups, the clause assignment
  (`sigma`) and the integer rows of `C_{t,g}`; the replacement forms `forms[e][k]` as `{variable: [coefficients in T]}`
  with exact rationals as strings; construction facts under `info`.
- `results/E1_toy.json` — Section 4: per run, the design points with the measurement-algorithm value `Z` and the
  brute-force value `H_brute`, the three costs of (2.11), the Taylor stage (restricted sums, coefficients) and `H0`.
- `results/E2_components.json` — Section 5: largest within-group component per (n, r, seed).
- `results/E3_fibre.json` — Section 6: per group, the rows, the clauses (signs, own forms as residues mod p,
  foreign shifts), components, the three methods' counts and times, the histogram digest (and the histogram for k <= 12).
- `results/E4_constrained.json` — Section 7: full histograms, counter statistics, encodings.
- `results/independent_check.json` — verification run 2 (written by `code/independent_check.py`).
- `logs/*.txt` — stdout of each experiment.
